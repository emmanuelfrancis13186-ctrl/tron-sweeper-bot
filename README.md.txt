# TRON USDT Sweeper Bot

Monitors TRON wallet for USDT (TRC-20) and alerts when funds arrive.

## Environment Variables
- `SOURCE_ADDRESS`: Source wallet address
- `TARGET_ADDRESS`: Target wallet address  
- `SOURCE_PRIVATE_KEY`: Source wallet private key
- `TRONGRID_API_KEY`: Optional API key

## Deploy on Render
1. Connect this repo
2. Add environment variables
3. Deploy!
